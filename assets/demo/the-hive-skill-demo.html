The Hive Skill

A portable six-role council protocol for agentic coding hosts. Invoke once. Trust it to finish.

v0.3.0 · Apache-2.0 · Open Source
The Problem

AI Agents Are Powerful.
But Unstructured.

Without a protocol, coding agents wander, hallucinate, and lose context.

🌀

No Structure

Agents jump between tasks without clear handoffs or role separation

💸

Token Waste

Redundant context, repeated inspections, bloated outputs drain budgets

🚫

No Stop Rules

Agents loop forever or stop prematurely with no clear completion criteria

The Council

Six Roles. One Hive Mind.

Each role has a focused mandate, evidence rules, and explicit handoff conditions.

👑
Queen
Orchestrates the council, classifies tasks, manages progress, enforces scope, makes final decisions
🔍
Scout
Maps repository, analyzes change impact, detects contradictions, delivers context bundle
📐
Architect
Creates executable plans, makes design decisions, classifies risk, assigns file scope
⚒️
Forger
Implements within assigned scope, runs incremental checks, classifies failures, produces patch manifest
🛡️
Sentinel
Validates across multiple layers, audits claims, runs adversarial scenarios, returns verdict
📜
Scribe
Synchronizes documentation, generates HIVE Review, prepares release evidence
